# 🌱 TouchGrass AI

> Get outside. Explore the real world.

TouchGrass AI is a local AI-powered outdoor mission generator.

It helps users turn their mood, available time, budget, and group size into a personalized outdoor activity.

## ✨ Features

- 😊 Mood-based activity suggestions
- ⏱️ Time-based recommendations
- 💰 Budget-aware missions
- 👥 Solo, friends, or family activities
- 📵 Phone-free outdoor challenge
- 🚶 Step-by-step mission plan
- 🤖 Local AI using Qwen3 4B
- 🔒 AI inference runs locally through Ollama

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Python
- Flask
- Ollama
- Qwen3 4B
